API de Livros
​Este é um projeto de API em Flask desenvolvido para a listagem de livros e autores através do método GET.

​Pré-requisitos
​Certifique-se de ter o Python instalado no computador.

​Instalação
​1. Clone o repositório ou baixe os ficheiros do projeto.
​2. No terminal, abra a pasta do projeto e instale as dependências necessárias com o comando:
pip install Flask

​Como executar
​1. Com o terminal aberto na pasta do projeto, inicie a aplicação executando:
python app.py
​2. O servidor ficará ativo localmente.

​Rotas disponíveis
​GET /livros: Devolve a lista completa de livros e autores registados em formato JSON.
Endereço da rota disponibilizada: http://127.0.0.1:5000/livros
